# Home Summaries

A Home Assistant integration providing dynamic per-area summary sensors

## For Developers

Please make sure you have installed Docker on your computer. Then, open the project's folder using the terminal and type the following command:

```sh
docker compose watch
```

Home Assistant will automatically restart whenever any file in the watched folder changes
